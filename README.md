# AFRetextures

DayZ retextures for Allied Forces.

## Flags

| Class name | Texture |
| --- | --- |
| `Flag_AF_Cummins` | `AFRetextures/flags/data/flag_af_cummins_co.paa` |

The artwork is an original illustration. The editable master is
`source/flag_af_cummins.svg` (3:2). The texture is that image squashed to
1024x1024, on the assumption that the flag mesh stretches the full square back
out to flag proportions; `flag_af_cummins_co.png` is the same image for preview.

## Building

1. Pack the `AFRetextures` folder to a PBO with DayZ Tools Addon Builder
   (prefix `AFRetextures`) and put it in `@AFRetextures/addons/`.
2. Add `Flag_AF_Cummins` to the server's `types.xml` (or spawn it by class name).

The `.paa` was generated by script rather than by DayZ Tools. If the game or
Addon Builder rejects it, re-export `flag_af_cummins_co.png` with ImageToPAA.
